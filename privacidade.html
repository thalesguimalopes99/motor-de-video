Motor de Video

Política de Privacidade

Atualizada em 9 de novembro de 2026.

Quem usa

O Motor de Video é uma ferramenta pessoal. Só o próprio operador conecta contas a ela. O aplicativo não coleta dados de visitantes, seguidores ou outras pessoas que usem seus serviços, porque não há outros usuários.

Dados acessados

  • YouTube: dados do canal do operador e permissão para enviar vídeos a ele.
  • Instagram e Facebook: dados das contas e Páginas do operador, permissão para publicar nelas e métricas públicas de perfis profissionais consultados por ele.

Como os dados são usados

Os dados servem apenas para publicar, agendar e acompanhar os posts do operador. Não são usados para publicidade nem para treinar modelos de IA.

Onde ficam

Dados e tokens de acesso ficam no computador do operador. Os tokens são guardados criptografados. O aplicativo não mantém servidor próprio.

Compartilhamento

Nenhum dado é vendido. As informações só saem do computador para os serviços necessários ao funcionamento:

  • YouTube, Instagram e Facebook, ao publicar o conteúdo escolhido pelo operador.
  • Anthropic (Claude API), que recebe somente os textos de frases e legendas para gerar variações. Dados de contas Google não são enviados.

Dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Remoção

O operador pode desconectar uma conta no aplicativo, o que apaga os tokens locais, e revogar o acesso nas permissões da Conta Google ou nas configurações de apps da Meta.
